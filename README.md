## Learning Path

A practical progression through this collection:

1. **Build enumeration skills**  
   Start with Breakout Enumeration Lab and Breakout by Enumeration.

2. **Practice Linux file hunting**  
   Continue with Breakout Bash: Linux File Hunt and learn to inspect relevant files and permissions.

3. **Understand capabilities**  
   Work through Getcap Breakout, Cap DAC Reader Breakout, and Captarnished.

4. **Connect capabilities with SUID and TAR**  
   Continue with Cap SUID Breakout, Cap the TAR, and File Capabilities: TAR to Root.

5. **Develop research skills**  
   Complete CVE Clue Hunt and Breakout and Research to practice connecting technical observations with vulnerability research.

6. **Finish with user-level access**  
   Use Breakout to User Flag as a practical progression challenge.

## How to Use the Labs

- Use every lab only in an authorized CTF or training environment.
- Begin with enumeration and understand the system before investigating possible breakout paths.
- Record permissions, capabilities, binaries, files, and configuration findings.
- Learn what Linux capabilities mean rather than treating `getcap` output as a shortcut.
- Research CVE references carefully and understand the underlying security issue.
- Document both the offensive learning objective and the corresponding defensive lesson.
- Review system hardening measures after completing each challenge.
